# SQL

`lead_engine_schema.sql` creates the tables the workflows use and inserts one placeholder `businesses_config` row.

1. In Supabase, open SQL Editor, New query.
2. Paste the file and click Run.
3. Edit the seed row (templates, search queries, notify email) before using it.

Columns marked `[workflows]` were inferred from the queries inside the exported workflows. All seed values are examples, not real business data.
